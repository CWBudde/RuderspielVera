# Ruderspiel – Spielregeln und Spielkonzept

**Stand:** 27. November 2026  
**Status:** Gemeinsamer Regelentwurf für Brettspiel und Computerspiel  
**Mitspieler:** 2–4

Dieses Dokument führt die handschriftlichen Aufzeichnungen und die anschließend gemeinsam besprochenen Regeln zusammen. Neuere ausdrücklich getroffene Entscheidungen haben Vorrang vor älteren Notizen. Noch nicht festgelegte Details sind mit **Offen** oder **Vorläufig** gekennzeichnet. Die Namen im Kartenverzeichnis sind nach der Handschrift übertragen und teilweise noch zu überprüfen.

## 1. Spielidee und Ziel

Jeder Mitspieler leitet eine eigene Rudermannschaft durch eine vollständige Rudersaison. Er verwaltet seine Ruderer, Boote und Trainer, entwickelt die Mannschaft im Training weiter, erhält besondere Eventkarten und stellt für die verschiedenen Wettkämpfe geeignete Mannschaften zusammen.

Gewinner ist, wer nach der letzten Regatta die meisten Medaillenpunkte gesammelt hat. Nicht allein der Sieg bei der letzten Regatta entscheidet über den Spielsieg.

| Platzierung in einem Rennen | Medaille | Medaillenpunkte |
| --------------------------- | -------- | --------------: |
| 1. Platz                    | Gold     |               2 |
| 2. Platz                    | Silber   |               1 |
| 3. Platz und schlechter     | Keine    |               0 |

Die Medaillenpunkte werden über die gesamte Saison addiert. Eine Goldmedaille ist somit doppelt so viel wert wie eine Silbermedaille.

### Gleichstände

Gleichstände bei Regatten sind ausdrücklich zulässig. Zwei Mannschaften mit gleicher höchster Leistung gewinnen beide Gold. Es wird kein zusätzlicher Würfelwurf zur Auflösung des Gleichstands benötigt.

**Offen:** Ob nach zwei ersten Plätzen der nächste Platz als zweiter oder dritter Platz zählt; Umgang mit Gleichständen auf dem zweiten Platz sowie in der Gesamtwertung am Saisonende.

### Motivation durch Siege

Mit jeder Goldmedaille wird zusätzlich ein Motivationspunkt vergeben. Dieser wird direkt nach der Regatta dem erfolgreichen Ruderer gutgeschrieben und kann somit bereits bei der nächsten Regatta wirksam werden. Silber bringt keinen entsprechenden Zusatzpunkt nach bisherigem Regelstand.

**Offen:** Ob bei einem siegreichen Mehrpersonenboot jedes Besatzungsmitglied +1 Motivation erhält (naheliegende Auslegung) und wie mehrere Goldmedaillen derselben Person innerhalb einer Regatta behandelt werden. Die Medaillenwertung von Mehrpersonenbooten (eine Medaille pro Rennen oder pro Besatzungsmitglied) ist ebenfalls noch ausdrücklich festzulegen.

## 2. Gemeinsamer Spielplan

Der Spielplan stellt den Jahreskreis einer Rudersaison dar. Es gibt genau eine gemeinsame Spielfigur, die als Kalenderzeiger dient.

- Alle Mitspieler befinden sich immer auf derselben Station.
- Die Figur wird jeweils zur nächsten vorgesehenen Station bewegt. Es gibt keinen individuellen Würfelwurf für die Bewegung.
- Jeder Schritt entspricht einem gemeinsamen Spielzug bzw. einer gemeinsamen Spielphase.
- Alle durchlaufen dieselben Regatten, Trainings, Events, Ereignisse und Sonderveranstaltungen.
- Entscheidungen über Mannschaften, Trainingspunkte und Trainer trifft jeder Mitspieler für sein eigenes Team.
- Würfel bzw. Zufallszahlen bestimmen einzelne Spielbedingungen, nicht die Bewegung auf dem Spielplan.

Beim Computerspiel übernimmt ein Zufallsgenerator die Rolle des Würfels.

### 2.1 Arten von Stationen

| Station             | Funktion                                                            |
| ------------------- | ------------------------------------------------------------------- |
| Spielvorbereitung   | Anfangskarten verteilen                                             |
| Training            | Eigenschaften der eigenen Ruderer verbessern                        |
| Event               | Personenbezogene Entwicklungskarten vergeben                        |
| Ereignis            | Allgemeine Überraschungen oder Änderungen des Spielgeschehens       |
| Regatta             | Wettkämpfe auf dem Wasser und Medaillenvergabe                      |
| Ergo-Cup            | Einzelwettkämpfe auf dem Ergometer                                  |
| Sonderveranstaltung | Zum Beispiel Motivation durch Basketball oder Winterruder-Fünfkampf |
| Trainingslager      | Erhöhte Zahl an Trainingspunkten                                    |
| JTFO                | Wettkampf mit besonderen Mannschaftskonfigurationen                 |
| Endspurtregatta     | Saisonabschluss mit besonderen Mixed-Mannschaften                   |

Events und Ereignisse sind bewusst unterschiedliche Stationstypen: Events entwickeln einzelne Ruderer dauerhaft oder über längere Zeit weiter. Ereignisse können die äußeren Rahmenbedingungen des Spiels beeinflussen.

### 2.2 Saisonkalender

Die folgende Reihenfolge ist aus dem handschriftlichen Ablauf übernommen. Jede durch einen Pfeil getrennte Station entspricht einer vorgesehenen Phase; die Zeilen dienen lediglich der Übersicht.

| Abschnitt | Stationen in zeitlicher Reihenfolge                                              |
| --------- | -------------------------------------------------------------------------------- |
| 1         | Spielvorbereitung → Training → Hildesheim                                        |
| 2         | Event → Training → Ereignis → Mindoor-Cup                                        |
| 3         | Event → WR5 (Winterruder-Fünfkampf) → Training → Ereignis → DRC-Ergo-Cup         |
| 4         | Event → Training → Ereignis → Osnabrücker Ergo-Cup                               |
| 5         | Event → Basketballturnier → Training → Ereignis → Hankensbüttel → Regatta Bremen |
| 6         | Event → Training → Ereignis → Kassel → Kasselregatta                             |
| 7         | Event → Training → Ereignis → Verbandsregatta I                                  |
| 8         | Event → Wanderfahrt → Training → Ereignis → Regatta Schillerschule               |
| 9         | Event → Training → Ereignis → Verbandsregatta II                                 |
| 10        | Event → Training → Ereignis → JTFO                                               |
| 11        | Event → Training → Ereignis → RVH-Regatta (Herbstsprintregatta)                  |
| 12        | Event → Training → Ereignis → RVB-Endspurtregatta                                |

Danach erfolgt die abschließende Medaillenwertung.

**Offen:** Der Mindoor-Cup wurde im Gespräch auch Mindero-Cup genannt; die endgültige Schreibweise ist zu prüfen. Ob Hankensbüttel und Kassel jeweils eigene Wettkämpfe, Trainingslager oder sonstige Stationen sind, geht aus dem Ablauf nicht zweifelsfrei hervor. Auch die genaue Funktion der Wanderfahrt ist offen. Die beiden Verbandsregatten sind zur Unterscheidung nummeriert; die Nummern sind keine offiziellen Namen. Die Position(en) des Trainingslagers müssen noch zugeordnet werden. In den Notizen sind RVH-Herbstsprintregatta und RVB-Endspurtregatta getrennte Stationen; das Spiel endet nach mündlicher Festlegung mit der RVB-Endspurtregatta.

## 3. Spielmaterial

Das Spiel sieht folgende Komponenten bzw. entsprechende digitale Objekte vor:

- Gemeinsamer Saisonspielplan und eine Kalenderfigur
- Rudererkarten in drei Altersgruppen
- Bootskarten der Kategorien Einer, Zweier und Vierer
- Sonder-Achter für die Endspurtregatta
- Trainerkarten
- Personenbezogene Eventkarten
- Allgemeine Ereigniskarten
- Gold- und Silbermedaillen bzw. entsprechende Zähler
- Trainings- und Motivationswerte auf Rudererkarten bzw. digitale Werte
- Würfel bzw. Zufallsgenerator

Skulls als eigenständige Spielmaterialien sind gestrichen. Die normalen Achterkarten sind ebenfalls gestrichen; nur bei der Endspurtregatta kann ein für alle identischer Achter verwendet werden.

## 4. Spielvorbereitung und Kartenverteilung

Das Spiel ist für zwei, drei oder vier Mitspieler ausgelegt.

### 4.1 Ruderer

Die handschriftliche Spielvorbereitung nennt drei Ruderer je Altersgruppe (Kinder, B-Junioren, A-Junioren). In der mündlichen Erklärung wurden außerdem drei Mädchen und drei Jungen genannt. Die genaue gemeinsame Verteilung nach Altersgruppe und Geschlecht ist deshalb noch zu bestätigen.

Festgelegt (27. November 2026): Die Zahl der Anfangsruderer hängt von der Zahl der Mitspieler ab. Jeder Mitspieler erhält je Altersgruppe mindestens ein Mädchen und einen Jungen, sonst zufällig:

| Mitspieler | Kinder | B-Junioren | A-Junioren | Pro Mitspieler | Verbleibend |
| ---------: | -----: | ---------: | ---------: | -------------: | ----------: |
|          2 |      6 |         13 |          7 |             26 |           3 |
|          3 |      4 |          9 |          5 |             18 |           1 |
|          4 |      3 |          4 |          3 |             10 |          15 |

Die ältere handschriftliche Rechentabelle mit neun Karten je Mitspieler (drei je Altersgruppe) ist damit überholt.

### 4.2 Boote

Zu Beginn steht jedem Mitspieler ein einfaches städtisches Boot jeder regulären Kategorie zur Verfügung:

- Einer
- Zweier
- Vierer

Die städtischen Boote haben einfache Leistungswerte. Später kommen bessere, schnellere Boote hinzu. Der vollständige vorgesehene Bootsbestand soll bis zum Saisonende verteilt sein.

### 4.3 Trainer

Zu Beginn erhält jeder Mitspieler nach dem gegenwärtigen Richtwert zwei Trainer. Die tatsächliche Anzahl kann von der Anzahl der Mitspieler abhängen.

### 4.4 Weitere Karten im Saisonverlauf

Die Mannschaften sollen sich auch durch neue Karten weiterentwickeln. Insbesondere sollen die Boote schrittweise verteilt werden. Als vorläufige Möglichkeit wurde genannt, nach Regatten weitere Karten zu vergeben.

**Offen:** Exakte Anfangsverteilung für zwei, drei und vier Mitspieler; Alters- und Geschlechtsquoten; Zeitpunkt, Anzahl und Auswahlverfahren zusätzlicher Ruderer, Boote und gegebenenfalls Trainer; Umgang mit Restkarten. Insbesondere ist noch nicht entschieden, ob Karten zufällig, per Auswahl oder abhängig von Wettkampfergebnissen verteilt werden.

## 5. Rudererkarten

Jede Karte repräsentiert einen konkreten Ruderer oder eine konkrete Ruderin.

### 5.1 Altersgruppen

- Kinder
- B-Junioren
- A-Junioren

Die Karten enthalten außerdem die für die Wettkampfeinteilung relevante Zuordnung zu Jungen oder Mädchen. Diese Zuordnung muss für den Kartensatz noch einzeln gepflegt werden.

### 5.2 Eigenschaften

Jeder Ruderer besitzt fünf numerische Eigenschaften:

| Eigenschaft     | Bedeutung im Spiel                                                              |
| --------------- | ------------------------------------------------------------------------------- |
| Kraft           | Relevant insbesondere für Ergo-Cups und weitere entsprechend definierte Rennen  |
| Ausdauer        | Relevant insbesondere für Langstreckenregatten                                  |
| Geschwindigkeit | Relevant insbesondere für Sprintregatten                                        |
| Technik         | Relevant insbesondere für reguläre Regatten und JTFO                            |
| Motivation      | Eigenständiger Leistungswert, relevant bei entsprechend definierten Wettkämpfen |

Die Eigenschaften können durch Training, Events und Sonderveranstaltungen dauerhaft wachsen. Es gibt keine feste Obergrenze.

### 5.3 Anfängliche Basiswerte

Für die erste Version wird eine gemeinsame Leistungsrangfolge verwendet. Michel (A-Junior) erhält als stärkster Ruderer einen anfänglichen Gesamtrichtwert von 100. Die folgenden Karten erhalten Richtwerte von 99, 98, 97 usw. Die schwächsten Karten liegen damit im zweistelligen Bereich.

Die konkreten Werte je Karte stehen in `docs/ruderspiel-basiswerte.md` (jeder Wert von 46 bis 100 genau einmal).

Der Richtwert ist die **Summe der fünf anfänglichen Eigenschaften**, kein zusätzlicher sechster Wert. Er dient der internen Kartenerstellung und Sortierung. Auf der Karte selbst muss die Summe nicht angezeigt werden.

Beispiel einer rein illustrativen Aufteilung von 100 Punkten (keine endgültigen Werte für Michel):

| Kraft | Ausdauer | Geschwindigkeit | Technik | Motivation | Summe |
| ----: | -------: | --------------: | ------: | ---------: | ----: |
|    30 |       25 |              15 |      20 |         10 |   100 |

Unterschiedliche Verteilungen erzeugen unterschiedliche Stärken. Eine Karte mit geringerer Gesamtsumme kann in einer einzelnen Disziplin besser sein als eine höher eingestufte Karte.

**Offen:** Die genaue Rangfolge sämtlicher Ruderer und alle fünf Basiswerte pro Karte. Die Schrittweite von einem Punkt ist das vorläufige Startmodell.

### 5.4 Persönliche Spezialfähigkeiten

Eine Rudererkarte kann im Saisonverlauf durch genau eine Eventkarte ergänzt werden. Persönliche Wettervorlieben sind in der Grundversion nicht allgemein vorgesehen; sie können später ergänzt werden. Das bereits vorgesehene Wetter-Event stellt eine mögliche gezielte Ausnahme dar, deren Umsetzung noch festzulegen ist.

## 6. Boote

### 6.1 Kategorien

| Kategorie                    | Bezeichnung in den Notizen | Besatzung |
| ---------------------------- | -------------------------- | --------: |
| Einer                        | 1x                         |         1 |
| Zweier                       | 2x                         |         2 |
| Vierer                       | 4x                         |         4 |
| Achter (nur Endspurtregatta) | 8x                         |         8 |

Boote müssen entsprechend der jeweiligen Wettkampfregeln eingesetzt werden.

### 6.2 Leistung

Ein normales Boot hat einen Leistungswert von höchstens 10 Punkten. Die städtischen Boote haben einfache Werte; bessere Boote können höhere Werte besitzen. Der Bootswert geht einmal pro Boot in die Leistung des jeweiligen Rennens ein.

Der Sonder-Achter bei der Endspurtregatta ist für alle Mitspieler gleich. Sein Bootswert soll daher keinen Wettbewerbsvorteil erzeugen.

**Offen:** Konkrete Bootswerte, Einteilung aller Boote nach Qualität, endgültiger Bootsbestand und die Frage, ob der Achter rechnerisch mit null oder einem für alle identischen Wert eingeht.

## 7. Trainer

Trainer besitzen keinen allgemeinen Leistungsgrundwert. Stattdessen bringen sie individuelle Spezialfähigkeiten mit, insbesondere wetterabhängige Vorteile oder Nachteile.

Beispiel aus der Besprechung (noch kein festgelegtes Kartenprofil): Herr Sack könnte bei Sonne +5 Punkte und bei Regen −5 Punkte bewirken.

### 7.1 Einsatz bei Regatten

- Jeder Mitspieler setzt für eine Regatta genau einen seiner Trainer ein.
- Dieser Trainer gilt für alle Boote und Mannschaften dieses Mitspielers bei derselben Regatta.
- Die Trainerwahl ermöglicht eine strategische Reaktion auf das gemeinsame Wetter.
- Es gibt keine allgemeine Trainerpunktzahl zusätzlich zu den Spezialeffekten.

**Offen:** Konkrete Spezialfähigkeiten und deren Werte für jeden Trainer; Auswahlzeitpunkt des Trainers im Verhältnis zur Wetterermittlung und Mannschaftsmeldung; ob der Effekt bei jedem einzelnen Boot oder auf eine andere Weise verrechnet wird; Bedeutung der Trainer bei Ergo-Cups oder Trainings.

## 8. Wetter

Vor jeder Regatta auf dem Wasser wird ein gemeinsames Wetter für alle Mitspieler bestimmt. Das Wetter bleibt für die gesamte jeweilige Regatta gültig.

| Ergebnis des sechsseitigen Würfels (Zuordnung beispielhaft) | Wetter | Wahrscheinlichkeit |
| ----------------------------------------------------------- | ------ | -----------------: |
| 1                                                           | Regen  |                1/6 |
| 2                                                           | Hitze  |                1/6 |
| 3                                                           | Wind   |                1/6 |
| 4                                                           | Kälte  |                1/6 |
| 5–6                                                         | Normal |                2/6 |

Das Wetter wirkt in der Grundregel ausschließlich über die Spezialfähigkeiten der Trainer. Es gibt keinen pauschalen Leistungsabzug, der alle Mannschaften gleichermaßen trifft. Diese Entscheidung wurde ausdrücklich bestätigt, weil ein gleicher Abzug bei einer rein relativen Wertung die Platzierung nicht ändern würde.

Das Beispiel „Sonne“ bei Herr Sack ist noch mit den Wetterkategorien abzugleichen (z. B. Hitze oder normales Wetter); eine zusätzliche Wetterkategorie ist noch nicht beschlossen.

**Offen:** Vollständige Wettereffekte pro Trainer und die genaue Umsetzung des persönlichen Wetter-Events. Für Ergo-Cups ist noch ausdrücklich zu entscheiden, ob Wetter überhaupt eine Rolle spielt; auf dem Ergometer sind die üblichen Wasserwettkampf-Zwischenfälle ausgeschlossen.

## 9. Training und Sonderveranstaltungen

### 9.1 Reguläres Training

Bei einem normalen Training erhält jeder Mitspieler insgesamt 10 Trainingspunkte. Er darf diese nach eigener Wahl auf seine Ruderer und deren fünf Eigenschaften verteilen. Die Punkte erhöhen die jeweiligen Werte dauerhaft.

Beispiel (nur zur Veranschaulichung): 4 Punkte auf die Ausdauer eines Ruderers, 3 auf die Technik einer Ruderin und 3 auf die Geschwindigkeit eines weiteren Ruderers.

Die Punkte werden für eine Eigenschaft des Ruderers vergeben, nicht als allgemeiner Zusatzwert, der bei jedem Rennen unabhängig von der Disziplin zählen würde. So werden die erworbenen Trainingspunkte beim Wettkampf nicht doppelt angerechnet.

Eventkarten können zusätzliche Auswirkungen auf das Training haben, etwa automatisches Wachstum einer Eigenschaft.

### 9.2 Trainings-Events / Trainingslager

Besondere Trainings-Events können bis zu 30 Trainingspunkte bringen. In den Notizen steht zum Trainingslager: „+30 Trainingspunkte, 5 Personen“. Die Auswahl bzw. Verteilung darf der Mitspieler selbst bestimmen.

**Offen:** Ob die 30 Punkte im Trainingslager insgesamt oder pro Person gelten, ob genau fünf Personen ausgewählt werden müssen und wie frei die Verteilung zwischen ihnen ist. Ebenso ist noch zu definieren, welche Trainings-Events es außer dem Trainingslager gibt. Für normales Training wurden keine Ermüdungs- oder Fatigue-Regeln festgelegt.

### 9.3 Winterruder-Fünfkampf (WR5)

Jeder Mitspieler wählt fünf seiner Ruderer aus. Jede dieser Personen erhält +10 Motivation.

### 9.4 Basketballturnier

Jeder Mitspieler wählt ebenfalls fünf seiner Ruderer aus. Jede ausgewählte Person erhält +10 Motivation.

Diese Sonderveranstaltungen dienen der Mannschaftsentwicklung. Ein eigener Medaillenwettkampf oder eine weitere Wertung wurde dafür nicht festgelegt.

### 9.5 Wanderfahrt

Die Wanderfahrt ist im Kalender vorgesehen. Ihre spielmechanischen Auswirkungen sind noch offen.

## 10. Wettkämpfe und Leistungsberechnung

### 10.1 Grundprinzip

Jede Regatta enthält Wettkämpfe mit eigenen Regeln: Altersgruppen, Geschlechtsklassen, zugelassene Boote und relevante Eigenschaften können sich unterscheiden.

Die Mannschaft mit der höchsten Gesamtleistung gewinnt ihr Rennen. Bei Gleichständen können mehrere Mannschaften denselben Platz erreichen.

In die Leistung fließen ein:

1. Die für das konkrete Rennen relevanten Eigenschaften der eingesetzten Ruderer, einschließlich aller bis dahin erworbenen Trainings- und Motivationspunkte.
2. Der Leistungswert des Bootes, falls ein Boot verwendet wird.
3. Anwendbare Spezialeffekte des ausgewählten Trainers, insbesondere wetterabhängige Effekte.
4. Anwendbare Spezialeffekte der Eventkarten.
5. Auswirkungen zufälliger Zwischenfälle.

Als Arbeitsmodell lässt sich ein regulärer Wasserwettkampf ohne Sonderfall wie folgt ausdrücken:

```text
Rudererleistung = Summe der gewichteten, relevanten Eigenschaftswerte
Mannschaftsleistung = Summe der Rudererleistungen
Rennleistung = Mannschaftsleistung + Bootswert
              + Trainereffekt + weitere Eventeffekte
              - gegebenenfalls Zwischenfallabzug
```

Die Formel konkretisiert die besprochene Summenregel. Sonderwirkungen (z. B. Verdopplungen oder Ausscheiden) können nicht immer als einfacher additiver Term behandelt werden. Die endgültigen Gewichte und die Reihenfolge solcher Sonderwirkungen sind noch zu definieren.

Basiswerte und Trainingszuwächse können getrennt gespeichert werden, dürfen jedoch nur einmal in die Leistung eingehen. Nicht relevante Eigenschaften tragen bei einem Rennen nicht automatisch zur Leistung bei.

### 10.2 Zufällige Zwischenfälle auf dem Wasser

| Zwischenfall                        | Wahrscheinlichkeit | Folge                                                                                                       |
| ----------------------------------- | -----------------: | ----------------------------------------------------------------------------------------------------------- |
| Kentern                             |                5 % | Die Mannschaft erreicht das Ziel sehr langsam, gegebenenfalls schwimmend; sie landet auf dem letzten Platz. |
| Materialschaden / etwas geht kaputt |               10 % | Die Mannschaft kann das Rennen nicht fortsetzen und scheidet aus.                                           |
| Krebs fangen                        |               15 % | Abzug von 10 Leistungspunkten.                                                                              |

Die Wahrscheinlichkeiten stehen in den handschriftlichen Notizen; die Werte für Kentern und Materialschaden wurden mündlich bestätigt. Der Abzug von 10 Punkten beim Krebsfangen wurde im anschließenden Gespräch vereinbart.

**Offen:** Ob die Ereignisse unabhängig pro Boot/Rennen ausgelost werden oder sich gegenseitig ausschließen; ob mehrere Zwischenfälle gleichzeitig möglich sind; Vorrang bei mehreren Zwischenfällen; Platzierung mehrerer gekenterter Mannschaften und Medaillenberechtigung, wenn wenige Mannschaften regulär ins Ziel kommen. Es wurde noch keine 70-%-Regel für störungsfreie Rennen beschlossen, weil dies von der Auswahlmethode abhängt.

### 10.3 Typischer Ablauf einer Regatta

Die folgenden Schritte beschreiben die funktionalen Bestandteile, nicht die endgültig festgelegte Reihenfolge der Entscheidungen:

- Gemeinsames Wetter ermitteln (Wasserregatta).
- Zulässige Mannschaften und Boote für die einzelnen Rennen zusammenstellen.
- Einen Trainer pro Mitspieler für die gesamte Regatta bestimmen.
- Relevante Eigenschaften und Spezialeffekte auswerten.
- Zufällige Zwischenfälle bestimmen (Wasserregatta).
- Platzierungen ermitteln.
- Medaillen und unmittelbar die Gold-Motivationspunkte vergeben.
- Gegebenenfalls neue Karten verteilen, sobald hierfür Regeln festgelegt wurden.

**Offen:** Ob Mannschaftsaufstellung und Trainerwahl vor oder nach Bekanntgabe des Wetters stattfinden; Anzahl der Meldungen pro Rennen; ob derselbe Ruderer in mehreren Rennen derselben Regatta starten darf.

## 11. Wettkampfformate

| Format                  | Eigenschaften nach jetzigem Stand                                                       | Zugelassene Kategorien                                                                         |
| ----------------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Hildesheim              | Ausdauer, Motivation                                                                    | Einer, Zweier; A- und B-Junioren                                                               |
| Ergo-Cup                | Kraft, Motivation                                                                       | Einzelwettkampf, alle Altersgruppen, getrennt nach Jungen und Mädchen                          |
| Reguläre Regatta        | Geschwindigkeit, Technik; je nach Regatta auch andere Kombinationen                     | Einer, Zweier, Vierer; Altersgruppen und Geschlecht getrennt gemäß Notizen                     |
| JTFO                    | Geschwindigkeit, Technik (aus Notizen zur Regatta-Gruppe; im Detail noch zu bestätigen) | Spezielle Kombinationen aus Zweiern und Vierern                                                |
| RVH-Herbstsprintregatta | Noch nicht einzeln definiert                                                            | Noch festzulegen                                                                               |
| RVB-Endspurtregatta     | Geschwindigkeit zählt doppelt; weitere Eigenschaften offen                              | Alters- und geschlechtsübergreifende Mixed-Mannschaften, insbesondere Vierer und Sonder-Achter |

Soweit keine Gewichtung festgelegt ist, werden die Eigenschaften hier nur als relevant aufgeführt. Eine vollständige Matrix mit den Gewichten je Wettkampf ist noch zu erstellen.

### 11.1 Hildesheimer Regatta

Die erste Regatta der Saison ist eine Langstreckenregatta. Gestartet wird in Einern und Zweiern der A- und B-Junioren. Ausdauer ist die zentrale Eigenschaft; Motivation ist laut Notiz und späterer mündlicher Erläuterung ebenfalls relevant. Die konkreten Gewichte sind noch offen.

Wetter, Bootswert, Trainer-Spezialfähigkeiten und Wasserwettkampf-Zwischenfälle gelten nach den allgemeinen Regeln.

### 11.2 Ergo-Cups

Vorgesehene Veranstaltungen:

- Mindoor-Cup
- DRC-Ergo-Cup
- Osnabrücker Ergo-Cup

Jeder Wettkampf wird einzeln auf dem Ergometer ausgetragen, getrennt nach Altersgruppe sowie Jungen und Mädchen. Ein Mixed-Wettkampf ist hier nicht vorgesehen.

Kraft und Motivation zählen zur Leistung. Es gibt keinen Bootswert und keine Zwischenfälle durch Kentern, Materialschaden oder Krebsfangen. Ein besonderer Trainer- bzw. Eventeffekt ist nur zu berücksichtigen, soweit er ausdrücklich für diesen Wettkampf gilt.

### 11.3 Reguläre Regatten

Unter anderem sind die Regatta Bremen, Kasselregatta, beide Verbandsregatten und die Regatta Schillerschule im Saisonkalender vorgesehen.

Die Notizen nennen Einer, Zweier und Vierer in jeder Altersgruppe, getrennt nach Jungen und Mädchen. Als Eigenschaften sind dort Geschwindigkeit und Technik genannt. Mündlich wurde ergänzt, dass manche Regatten auch Geschwindigkeit und Kraft oder andere Kombinationen verwenden können.

Wetter und Zwischenfälle entsprechen grundsätzlich den allgemeinen Wasserregeln. Die konkrete Liste aller Rennen pro Veranstaltung muss noch festgelegt werden.

### 11.4 Jugend trainiert für Olympia (JTFO)

JTFO besitzt besondere Mannschaftskonfigurationen. Die handschriftlichen Notizen sehen folgende Varianten vor:

| Variante | Boote        | Benötigte Plätze |
| -------- | ------------ | ---------------: |
| A        | 2x + 2x + 2x |                6 |
| B        | 2x + 4x + 2x |                8 |
| C        | 2x + 4x + 4x |               10 |

Je nach Anzahl der Mitspieler und verfügbaren Ruderern kann eine andere Konfiguration sinnvoll oder erforderlich sein. Bei zwei Mitspielern stehen tendenziell mehr Ruderer pro Mitspieler zur Verfügung, wodurch Vierer leichter besetzt werden können.

**Offen:** Genaue Zuordnung der Varianten zu zwei, drei und vier Mitspielern; Zulässigkeit unterschiedlicher Konfigurationen bei derselben Regatta; Alters- und Geschlechtsanforderungen; Wertung der Einzelrennen oder eines Gesamtwettkampfs. Die handschriftlichen Varianten enthalten keinen Dreier; die mündlich nicht eindeutig verstandene Formulierung wird daher nicht als zusätzliche Bootsklasse übernommen.

### 11.5 RVH-Herbstsprintregatta

Die Herbstsprintregatta des RVH ist die vorletzte im handschriftlichen Kalender genannte Regatta. Ihre individuellen Rennklassen und Eigenschaftsgewichte müssen noch definiert werden.

### 11.6 RVB-Endspurtregatta

Die Endspurtregatta des RVB bildet den Abschluss der Saison.

- Geschwindigkeit wird doppelt gewichtet.
- Altersgruppen dürfen in generationsübergreifenden Mannschaften gemischt werden.
- Jungen und Mädchen dürfen gemeinsam antreten.
- Insbesondere generationsübergreifende Mixed-Vierer und Mixed-Achter sind vorgesehen.
- Der Achter darf ausschließlich hier vorkommen und ist für alle Mitspieler gleich. Das Boot selbst verschafft dadurch keinen Vorteil.
- Auch hier werden Medaillen für die Saisonwertung gewonnen.

In der mündlichen Besprechung wurden außerdem weitere Mixed- und altersübergreifende Besetzungen angedeutet.

**Offen:** Die vollständige Liste der Rennen, ob auch Mixed-Einer oder -Zweier bzw. weitere Zweierklassen vorgesehen sind, genaue Mindestanforderungen an Alters- und Geschlechtsmischung, zusätzliche relevante Eigenschaften neben der doppelt gewichteten Geschwindigkeit, etwaige spezielle Medaillenchancen.

## 12. Personenbezogene Events

Events sind ein zentrales Element der individuellen Mannschaftsentwicklung. Sie sollen nicht nur Zahlen erhöhen, sondern den Rudererkarten auch besondere Fähigkeiten, Entwicklungswege oder Aufgaben geben.

### 12.1 Vergabe

- Alle Mitspieler erleben jedes Event gleichzeitig.
- Bei einem Event erhält jeder Mitspieler gleich viele Eventkarten.
- Die Anzahl darf sich je nach Event und Saisonfortschritt unterscheiden.
- Das erste Event beginnt mit genau einer Karte pro Mitspieler.
- In späteren Events kann die Anzahl langsam steigen, beispielsweise auf zwei Karten. Gegen Ende der Saison soll die Varianz größer werden.
- Jede Eventkarte ist einer konkreten eigenen Rudererkarte zugeordnet. Der Mitspieler kann nicht frei bestimmen, auf wen die Karte angewendet wird.
- Ein Ruderer darf im gesamten Saisonverlauf höchstens eine Eventkarte erhalten. Kombinationen mehrerer Eventkarten auf derselben Person sind nicht erlaubt.
- Daraus ergibt sich eine natürliche Obergrenze für die Zahl an verteilbaren Events: die Zahl der eigenen Ruderer, die noch keine Eventkarte besitzen.

Die Anzahl der Karten pro Station muss daher mit den verfügbaren Ruderern und der Gesamtzahl der Eventstationen abgestimmt werden. Insbesondere dürfen die frühen Events nicht schon alle möglichen Personen aufwerten.

Beispiele der personenbezogenen Zuordnung: „Mystery Mara“ gilt nur für Mara; „Technik Jara“ nur für Jara; ein Tausch-Event bei Vera erlaubt ausschließlich die Veränderung von Veras Eigenschaften. Die Namen dienen hier zur Illustration, nicht als endgültige Kartenbenennungen.

**Offen:** Konkreter Ausschüttungsplan pro Eventstation, Zufalls- oder Auswahlmechanismus für Eventtyp und Person, Umgang mit ungleichen Restbeständen noch nicht aufgewerteter Ruderer, genaue Anzahl physischer Eventkarten. Alle Spieler sollen weiterhin gleich viele Karten erhalten; wie dies bei fehlenden berechtigten Personen durchgesetzt wird, ist noch festzulegen.

### 12.2 Die zwölf ausgewählten Eventtypen

Die Liste folgt der handschriftlichen Eventseite. Die Kurznamen sind teilweise redaktionelle Arbeitsbezeichnungen.

| Nr. | Event                           | Regel bzw. vorgesehene Wirkung                                                                                                                                                                                        |
| --: | ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|   1 | Wetter-Event                    | Der Notiz zufolge erhält jeder ein gutes Wetter; nach der späteren personenbezogenen Vergaberegel soll der Effekt einer konkreten Rudererkarte zugeordnet werden. Wie gutes Wetter individuell wirkt, ist noch offen. |
|   2 | Wachstum                        | Eine Eigenschaft des zugeordneten Ruderers wächst bei jedem Training automatisch. Zuwachs und Wahl der Eigenschaft sind offen.                                                                                        |
|   3 | Phönix / Schwächste Eigenschaft | Die schwächste Eigenschaft des Ruderers erhöht sich um 5 Punkte.                                                                                                                                                      |
|   4 | Tausch-Event                    | Die Eigenschaftspunkte dieses Ruderers dürfen getauscht bzw. umverteilt werden. Andere Ruderer sind nicht betroffen. Die genaue Tauschregel ist offen.                                                                |
|   5 | Verdopplung                     | Die beste Eigenschaft des Ruderers wird verdoppelt.                                                                                                                                                                   |
|   6 | Kraft-Event                     | Besondere Aufwertung der Kraft des zugeordneten Ruderers. Umfang offen.                                                                                                                                               |
|   7 | Ausdauer-Event                  | Besondere Aufwertung der Ausdauer. Umfang offen.                                                                                                                                                                      |
|   8 | Geschwindigkeits-Event          | Besondere Aufwertung der Geschwindigkeit. Umfang offen.                                                                                                                                                               |
|   9 | Technik-Event                   | Besondere Aufwertung der Technik. Umfang offen.                                                                                                                                                                       |
|  10 | Motivations-Event               | Besondere Aufwertung der Motivation. Umfang offen.                                                                                                                                                                    |
|  11 | Seelenzwilling                  | Eine zusätzliche Rudererkarte mit denselben bisherigen Trainingspunkten wie die zugeordnete Person.                                                                                                                   |
|  12 | Geheime Mission / Mystery       | Mit der Eventkarte erhält die zugeordnete Person eine geheime Mission, die sie selbst erfüllen muss.                                                                                                                  |

Die Notiz enthält zwölf Einträge; frühere Gesprächsbeiträge erwähnten zwischenzeitlich auch 13 Events. Ein dreizehnter ausgewählter Eventtyp ist in der vorliegenden finalen Liste nicht erkennbar.

### 12.3 Noch zu definierende Eventmechaniken

- Ob und wann bei Gleichstand mehrerer schwächster bzw. stärkster Eigenschaften gewählt oder ausgelost wird.
- Ob Verdopplung und andere Änderungen den aktuellen Gesamtwert oder nur Basiswerte bzw. Trainingswerte betreffen, und ob sie dauerhaft oder zeitlich begrenzt sind.
- Ob beim Tausch nur vollständige Eigenschaftswerte vertauscht oder Punkte vollständig neu verteilt werden dürfen.
- Ob Wachstum bei jedem regulären Training und/oder auch bei Trainingslagern ausgelöst wird.
- Beim Seelenzwilling: Identität, Basiswerte, genaue Übernahme der Trainingspunkte, zusätzliche Startberechtigung und ob die zusätzliche Karte selbst noch ein Event erhalten darf.
- Bei geheimen Missionen: Aufgabenkatalog, Belohnungen, Auslöser, Fristen und Umgang mit unerfüllten Missionen.
- Beim Wetter-Event: persönlicher Effekt trotz des gemeinsamen Regattawetters und der sonstigen Trainerregel.
- Stärke und Balancing der fünf direkten Eigenschafts-Events.
- Wie Spezialwirkungen beim Computerspiel und auf physischen Karten eindeutig dargestellt werden.

### 12.4 Früher diskutierte Ideen, nicht als Regeln beschlossen

Die folgenden Konzepte waren Teil des Brainstormings, sind aber nicht Bestandteil der zwölf ausgewählten Eventtypen, soweit sie nicht bereits in diesen aufgehen: Evolution, Erwachen der Titanen, Quantenmutation, Adrenalinrausch, Maschsee-Magie, Schicksalswende, unendliches Potenzial, Hyperdrive, Pakt mit Neptun, Jackpot, das zweite Ich, Prophezeiung, Supernova, Orakel, Schatzkammer, Chamäleon und weitere experimentelle Regeländerungen. Ein Niykari-/Nyakari-Event wurde ebenfalls als Idee erwähnt. Die Schreibweise und Wirkung sind nicht festgelegt. Diese Ideen können bei einer späteren Erweiterung wieder aufgegriffen werden.

## 13. Allgemeine Ereignisse

Ereignisse sind von den personenbezogenen Entwicklungs-Events getrennt. Sie können auf dem gemeinsamen Saisonkalender vorkommen und alle Mitspieler gleichzeitig betreffen, ohne ihnen zwingend neue Eventkarten zu geben.

Als Ideen wurden unter anderem Trainerstreik, Trainer-Rebellion, Maschsee-Monster und andere überraschende Veränderungen genannt. Ein Trainerstreik könnte beispielsweise dazu führen, dass das nächste Training ohne Trainer auskommt, sofern Trainer bis dahin eine Trainingsfunktion erhalten. Diese Beispiele sind noch nicht als endgültige Regeln beschlossen.

**Offen:** Vollständiger Ereigniskatalog, Auslöser, Wahrscheinlichkeiten, Dauer, konkrete Wirkungen, und ob bzw. in welchem Umfang einzelne Ereignisse die ansonsten geltenden Trainer- oder Kartenbesitzregeln vorübergehend ändern dürfen. Insbesondere sind Karten- oder Ruderertausch zwischen Mitspielern nicht Teil der beschlossenen Entwicklungs-Eventmechanik.

## 15. Umsetzung als Computerspiel

Die Regeln sollen sowohl für ein klassisches Brettspiel als auch für ein Computerspiel gelten. Im digitalen Spiel gibt es keinen physischen Würfel; zufällige Ergebnisse werden vom Programm erzeugt.

Für die technische Umsetzung bietet sich folgende Struktur an (Vorschlag, keine zusätzlich beschlossene Spielregel):

| Objekt          | Wesentliche Daten                                                                                                     |
| --------------- | --------------------------------------------------------------------------------------------------------------------- |
| Spiel           | Mitspielerzahl, aktueller Kalenderschritt, Spielstatus                                                                |
| Mitspieler      | Eigene Ruderer, Boote, Trainer, Gold- und Silbermedaillen                                                             |
| Ruderer         | Eindeutige ID, Name, Altersgruppe, Geschlechtsklasse, fünf Basiswerte, Trainingsänderungen, höchstens eine Eventkarte |
| Boot            | ID, Name, Kategorie, Leistungswert, ggf. Qualitätsgruppe                                                              |
| Trainer         | ID, Name, Wettereffekte, weitere festgelegte Spezialfähigkeiten                                                       |
| Eventtyp        | Identität, Beschreibung, Auslösebedingung, Wirkung                                                                    |
| Eventkarte      | Eventtyp und fest zugeordnete Ruderer-ID, ggf. Mission und Fortschritt                                                |
| Ereignis        | Allgemeiner Effekt und ggf. Geltungsdauer                                                                             |
| Kalenderstation | Typ, Name, Reihenfolge, zugehörige Regeln                                                                             |
| Wettkampf       | Alters-/Geschlechtsklassen, Bootsklassen, Eigenschaftsgewichte, Sonderregeln                                          |
| Rennmeldung     | Mitspieler, Besatzung, Boot, gewählter Regattatrainer                                                                 |
| Rennergebnis    | Leistung, Zwischenfälle, Platzierung, Medaillen, Motivationszuwachs                                                   |

Wichtig für die Implementierung:

- Ein gemeinsamer Kalenderzustand steuert alle Mitspieler.
- Die Wetterermittlung erfolgt einmal pro Regatta.
- Die Kartenvergabe und Zwischenfälle benötigen eindeutige Zufallsregeln.
- Ein Ruderer kann nicht zwei Eventkarten erhalten.
- Ruderer mit gleichen Namen werden durch eindeutige IDs unterschieden.
- Eigenschaftswerte haben regeltechnisch kein Maximum.
- Trainingspunkte werden nicht doppelt in die Rennleistung eingerechnet.
- Gold-Motivationspunkte werden unmittelbar nach der Regatta wirksam.
- Gleichstände werden nicht künstlich aufgelöst.
- Bei der Endwertung wird die Summe `2 × Gold + Silber` verglichen.

Die technische Datenstruktur ist ein Ausgangspunkt. Noch unentschiedene Regeln sollten konfigurierbar gehalten oder bis zur Entscheidung ausdrücklich als Platzhalter behandelt werden.
