# Ruderspiel – PoC rules

The family's rules draft (`docs/ruderspiel-regelwerk.md`) leaves many points **Offen**. To make a
first playable computer version, this document fixes every missing rule. **Every rule below is a
PoC assumption** unless it quotes the Regelwerk directly; all of them can be changed by the family.
Numbers live in `internal/data/*.json`, not in code, so most changes are data edits:

| File | Content |
|---|---|
| `rules.json` | training points, camp, selections, incident probabilities, Krebs penalty, weather table, event cards per station, deal sizes, draft, medal points, Gold motivation, loan boat value, JTFO variants, boat/trainer scaling, guest crews |
| `calendar.json` | the 52 stations |
| `competitions.json` | weights, race lists and guest-crew offset per competition |
| `rowers.json` | 55 rower cards (generated by `cmd/gendata`, hand-editable) |
| `boats.json`, `trainers.json` | boat and trainer cards |
| `events.json`, `ereignisse.json`, `missions.json` | event deck, Ereignis deck, mission catalog |

## 1. Season and calendar

- PoC assumption: exactly the 12 sections of Regelwerk §2.2, 52 stations, played in order. The game
  ends after the RVB-Endspurtregatta.
- PoC assumption: **Hankensbüttel** and **Kassel** (the station before the Kasselregatta) are
  *Trainingslager* (camps).
- PoC assumption: **WR5**, **Basketballturnier** and **Wanderfahrt** are *selection* stations
  (choose 5 rowers).
- Mindor-Cup, DRC-Ergo-Cup and Osnabrücker Ergo-Cup are Ergo-Cups; JTFO is a team competition;
  Hildesheim, Bremen, Kassel, Verbandsregatta I/II, Schillerschule, RVH and RVB are water regattas.
- Counts: 12 trainings, 2 camps, 3 selections, 11 Event stations, 11 Ereignis stations, 12
  competitions.

## 2. Cards and starting deal

### 2.1 Rowers (Ruderer)

- 55 cards, names exactly from Regelwerk §14.1–14.3.
- PoC assumption: rank (= sum of the five starting stats incl. Motivation, §5.3) A-Junioren 100…86
  (Michel = 100, the others shuffled), B-Junioren 85…59, Kinder 58…46.
- PoC assumption: each sum is split by one of five archetypes with ±15 % jitter per stat, every stat
  ≥ 5:

  | Archetyp | Kraft | Ausdauer | Geschw. | Technik | Motivation |
  |---|---:|---:|---:|---:|---:|
  | Kraftpaket | 30 % | 20 % | 18 % | 16 % | 16 % |
  | Ausdauerläufer | 18 % | 30 % | 16 % | 18 % | 18 % |
  | Sprinter | 20 % | 15 % | 30 % | 19 % | 16 % |
  | Techniker | 16 % | 18 % | 19 % | 30 % | 17 % |
  | Kämpferherz | 19 % | 19 % | 17 % | 17 % | 28 % |

  `go run ./cmd/gendata` regenerates `rowers.json` deterministically (seed 2026). Values may be
  edited by hand afterwards; the loader checks that the stats still add up to the rank.
- IDs are `<name>-<age>` (e.g. `lea-b`, `lea-a`); the second Matilda among the A-Junioren is
  `matilda-a-2` with the display name "Matilda (2)".
- Stats have no maximum (§5.2) and never drop below 0.

### 2.3 Boats

- PoC assumption: every player starts with a city boat (*städtisches Boot*) 1x, 2x and 4x, value 3.
- PoC assumption: the named boats of §14.5 go into the draft pool. First group value 5–7, outlined
  second group value 8–10:

  | Class | First group (5–7) | Outlined group (8–10) |
  |---|---|---|
  | Einer | Ice-Man 6, Manpower 7, Kalypso 5, Reinfall 5 | Zwergenkreuzer 8, Traumstart 9, Rennschlumpf 8, Singlespeed 10 |
  | Zweier | Bj-Turbo 7, Black Sword 6, Goodspeed 5 | Freiheit 8, X-Wing 10, Laufwunder 9, H zwei O 8 |
  | Vierer | Simsalabim 6, Oshra 5, Need 4 Speed 7 | Q 10, 5 Freunde 9, Wilhelm 8 |

  Note: §14.5 lists **21** named boats (not 22).
- The shared RVB eight ("Endspurt-Achter") is identical for everyone and has value 0 (§6.2).
- PoC balancing rule: a boat's value counts **twice per seat** (`boatValuePerSeat`,
  `boatValueFactor: 2`): Singlespeed in the 1x = +20, Q in the 4x = +80, a city 4x = +24. The card
  values themselves stay as in §14.5.
- PoC assumption: at JTFO a player without a suitable free own boat gets a **Leihboot** (value 2).

### 2.5 Starting deal (any player count 2–4)

- PoC assumption: 9 rowers per player – 3 per age group, at least 1 girl and 1 boy per age group,
  otherwise random. With 3 players 28 rowers remain in the pool.
- City 1x/2x/4x and 2 random trainers per player. Remaining trainers (4 with 3 players) and all
  named boats go into the draft pool.

## 3. Training and special stations

- Training (§9.1): exactly 10 points per player, freely on own rowers and stats.
- Trainingslager: exactly 30 points on **at most 5** rowers, free split (PoC assumption).
- WR5 and Basketballturnier (§9.3/9.4): choose exactly 5 rowers, each +10 Motivation.
- Wanderfahrt: choose exactly 5 rowers, each +4 Ausdauer and +3 Motivation (PoC assumption).

## 4. Competitions

### 4.1 Order and scoring

- PoC assumption: the weather (d6, §8: 1 Regen, 2 Hitze, 3 Wind, 4 Kälte, 5–6 Normal) is rolled and
  shown **before** trainer choice and lineup, so the trainer is the reaction to the weather.
  Ergo-Cups have no weather.
- Each player picks one trainer for the whole competition (§7.1); required as soon as the player
  enters at least one race.
- Score per entry (§10.1 working model, PoC weights):
  `crew = Σ over rowers Σ weight·stat` (rounded at the end),
  `total = crew + boat value × 2 × seats + trainer effect × seats + event bonuses − Krebs penalty`.
- PoC assumption: per competition each player enters **at most one crew per race**; every rower
  starts **at most once** per competition and every boat is used **at most once** per competition.
  Races may be left empty.
- PoC assumption: in crew boats (2x, 4x) of the A and B categories, rowers of the next younger age
  group may row up (A races accept B, B races accept Kinder). Singles (1x) and ergos are strictly by
  age. This keeps crew races fillable with 3 rowers per age group.
- Ties are kept (§1). Ranking uses competition ranking (1, 1, 3): two golds → the next is third,
  no silver (PoC). A tie for second gives two silvers.
- One medal per **race entry**, not per crew member. Gold = 2 points, silver = 1 point (§1).
- Gold motivation (§1): every crew member of a gold boat gets +1 Motivation immediately.
- Empty races award nothing. A single finishing starter still has to beat the guest crew (4.6).

### 4.2 Incidents (water only, §10.2)

- PoC assumption: one d100 per boat entry, mutually exclusive: 1–5 Kentern, 6–15 Materialschaden,
  16–30 Krebs, else clean (70 %).
- Kentern: the crew finishes last (several capsized crews share the place after all finishers) and
  gets no medal. Materialschaden: DNF (place 0), no medal. Krebs: −10 points.
- No incidents at Ergo-Cups.

Kinder-Vierer is open to both genders (there are only 5 Kinder boys).

### 4.4 JTFO (§11.4)

- PoC assumption: variant by player count: 2 → C (2x + 4x + 4x), 3 → B (2x + 4x + 2x), 4 → A
  (2x + 2x + 2x). All ages and genders allowed.
- Each boat is scored and gets its own incident roll. Team score = sum of the boats; a capsized or
  broken boat contributes 0. One medal per team (gold/silver), Gold motivation for all team members.
  Missing own boats are replaced by Leihboote (value 2).

### 4.5 RVB-Endspurtregatta (§11.6)

- Mixed rule (PoC): at least one girl, one boy and two age groups per boat.
- Mixed-Vierer uses an own 4x; the Mixed-Achter uses the shared eight (value 0).

### 4.6 Gastmannschaften (guest crews)

PoC balancing rule (section 10). With at most one crew per player, a race has only 1–3 player
entries and nearly every starter used to medal. Every race with at least one player entry therefore
also has a **guest crew** from another club (`rules.json` `guests`):

- Every stat of a guest rower = `statLevel[oldest allowed age group] + growthPerStation × station
  index + guestOffset of the competition` (Kinder 15, B 19, A 23, growth 0.3 per station, so +15
  by the RVB-Endspurt).
- Guest total = `round(seats × Σ weights × level)` + guest boat value 5 (scaled like player boats,
  i.e. ×2 per seat; no boat at Ergo-Cups, value 0 in the shared eight). No trainer, no incidents.
- The guest crew is ranked like a player entry: if it is faster it takes gold (or silver) away,
  but it never scores points. At JTFO one guest team (sum of the guest boats) joins the team
  ranking only.
- `guestOffset` per competition evens out how hard the guests are (the bots' training concentrates
  on the stats of the next competitions): Hildesheim −4, Mindor-Cup +1.5, DRC-Ergo-Cup +5.5,
  Osnabrücker Ergo-Cup +6, Bremen −2.5, Verbandsregatta I −3.5, RVH −1.5, others 0.
- Guest scores are deterministic, so players (and bots) can compute them in advance.

## 5. Events (§12)

- PoC assumption: Event stations 1–6 give 1 card per player, 7–11 give 2 cards (at most 16 per
  player), each limited by the player's rowers without an event.
- The rower is drawn uniformly among own rowers without an event card (twins never get one); the
  type is drawn from a weighted deck:

| Event | Weight | Effect |
|---|---:|---|
| Wetter-Event | 8 | The rower's boat +4 at water regattas when the weather is not Normal |
| Wachstum | 8 | Best stat (current; ties → first in display order) +2 at every training and camp |
| Phönix | 10 | Weakest stat +5 immediately (ties drawn at random) |
| Tausch | 8 | The player may swap two stat values of this rower once (or skip) |
| Verdopplung | 5 | Current best stat doubled once, permanent (ties drawn at random) |
| Kraft/Ausdauer/Geschwindigkeits/Technik/Motivations-Event | 10 each | +8 on that stat |
| Seelenzwilling | 5 | New rower card "<Name> (Zwilling)", same age/gender, 80 % of the current stats (rounded); can't get an event |
| Geheime Mission | 8 | Random mission from the catalog (only missions still achievable) |

### 5.1 Mission catalog (Geheime Mission)

The mission text is visible only to its owner until it is fulfilled or failed. Missions are checked
after each competition; a mission fails as soon as it can no longer be fulfilled, and at season end.

| Mission | Reward |
|---|---|
| {Name} gewinnt Gold im Einer. | +10 on best stat |
| {Name} gewinnt Gold im Vierer. | +1 medal point |
| {Name} gewinnt Gold bei einem Ergo-Cup. | +1 medal point |
| {Name} gewinnt Gold vor JTFO. | +1 medal point |
| {Name} gewinnt eine Medaille (Gold oder Silber). | +10 on best stat |
| {Name} gewinnt Gold bei Regen, Hitze, Wind oder Kälte. | +10 on best stat |
| {Name} startet bei 3 weiteren Wettkämpfen. | +10 on best stat |
| {Name} holt mit dem Team bei JTFO eine Medaille. | +1 medal point |
| {Name} gewinnt Gold bei der RVB-Endspurtregatta. | +1 medal point |

## 6. Ereignisse (§13)

PoC assumption: one card per Ereignis station, drawn with replacement (all weights equal), shown to
everyone. Immediate effects apply at once; the others wait until the next matching station.

| Ereignis | Effect |
|---|---|
| Trainerstreik | Next regular training: 5 points |
| Doppeltraining | Next regular training: 15 points |
| Maschsee-Monster | Next water regatta: Krebs probability 30 % |
| Grippewelle | Immediately: one random rower per team −5 Motivation |
| Vereinsfest | Immediately: every rower +1 Motivation |
| Neue Ergometer | Next Ergo-Cup: Kraft weight 3 |
| Sponsor | Next draft: the player with the fewest medal points picks one extra card |
| Hitzewelle | Next water regatta: weather is Hitze |
| Ruhige Woche | Nothing |
| Bootshaus-Renovierung | Next water regatta: city boats −1 |

If several training modifiers are pending, the most recent one wins.

## 7. Draft (new cards during the season)

- PoC assumption: after every competition except the last, the players pick cards one after another
  from an open offer of (players + 1) cards drawn from the pool. The offer contains at least one boat
  while boats remain; trainers are offered from section 5 on.
- Pick order: fewest medal points first, then fewer golds, then seat order (catch-up).
- Unpicked cards return to the pool.

## 8. Season end

- After the RVB-Endspurtregatta. Points = 2 × Gold + Silber + mission points; most points win, ties
  share the win (PoC).

## 9. Computer version details

- All randomness comes from one seeded generator drawn in a fixed order; a game is fully defined by
  its seed and decision log.
- Opponents' lineups and trainer choices stay hidden until the competition is resolved; all cards on
  the table (rowers, boats, trainers, event cards) are public, mission texts excepted.

## 10. Balancing pass (Phase 3)

Tool: `just sim` / `go run ./cmd/sim -games 1000 -seed 1 [-players 3] [-mode default|taktiker|bauch|rotate]`
plays all-bot seasons with `internal/bot` (seat 1 Taktiker, seats 0/2 Bauchgefühl in `default`).

Changes (all data-driven):

1. Boat value ×2 per seat (`boatValuePerSeat: true`, `boatValueFactor: 2`).
2. Trainer effects per seat (`trainerPerSeat: true`) and doubled on the cards (`trainers.json`).
3. Guest crews in every contested race (`guests`, `guestOffset`; section 4.6).

Engine hooks added for this: `Rules.BoatScale/TrainerScale`, `engine.GuestScore`, guest rows in
`resolveCompetition` (`EntryResult.guest`). Medal rules, race lists and incidents are unchanged.

Sim numbers, 1000 games, seed 1, 3 players:

| Metric | Before | After |
|---|---|---|
| Final points mean (sd) | 54.3 (7.4) | 34.1 (4.8) |
| Final points min / p10 / median / p90 / max | 31 / 45 / 54 / 64 / 80 | 18 / 28 / 34 / 40 / 52 |
| Share of final scores in 15..40 | 2.4 % | 91.4 % |
| Winner minus last | 14.7 | 9.1 |
| Gold / silver per player and season | 19.9 / 14.3 | 10.4 / 13.3 |
| Win rate Taktiker (1 vs 2 Bauchgefühl) | 57.1 % | 41.0 % |
| Win rate per Bauchgefühl seat | 22.7 % / 20.1 % | 29.4 % / 29.6 % |
| Max seat win rate, all seats Taktiker | 35.0 % | 35.4 % |
| Score share crew / boat / trainer | 95.7 / 3.1 / 1.0 % | 83.9 / 12.1 / 3.8 % |
| Contested races decided by the boat / by the trainer | 2.3 % / 5.8 % | 6.1 % / 9.9 % |
| Guest crew 1st / top 2 in contested races | – | 49.6 % / 79.0 % |
| Player entries per race; races with 0/1/2/3 entrants | 2.2; 8 / 17 / 20 / 55 % | unchanged |
| Incidents per water entry (Kentern / Material / Krebs) | 4.9 / 10.0 / 16.9 % | unchanged |

The "before" Taktiker edge was larger because the old rules let a well-optimised lineup medal
almost everywhere; the gap between the personalities is now set in `internal/bot` (Taktiker:
2 % perception noise, 8 local-search passes; Bauchgefühl: 7 %, 1 pass).

Known limits: 2-player games still average ~42 points (4 players ~30), because the target was set
for 3 players. Krebs (−10) is now small against entry totals of 60–550 and could be scaled per
seat. Boat draft picks are ~50 % of all picks because an extra boat also allows an extra entry
(players start with one boat per class).
