# Translations

German is the default language and English the second. The UI picks German when the browser
prefers German and English otherwise; the DE/EN toggle (start screen, header, menu) overrides that
and is saved in localStorage (`ruderspiel.lang`).

## Where text lives

| Text                                                          | German                                   | English                       |
| ------------------------------------------------------------- | ---------------------------------------- | ----------------------------- |
| UI (buttons, labels, hints)                                   | `web/src/i18n/ui.de.ts` (source of keys) | `web/src/i18n/ui.en.ts`       |
| Engine messages (log, prompts, notes, errors)                 | `web/src/i18n/messages.de.ts`            | `web/src/i18n/messages.en.ts` |
| Rule data (stations, races, cards, trainers, boats, missions) | `internal/data/*.json`                   | `internal/data/i18n/en.json`  |

`just gen-i18n` (`cmd/geni18n`) writes the data texts of both languages into
`web/src/i18n/data.gen.ts`. Run it after changing a text in `internal/data`.

## How the engine talks

`internal/engine` emits `engine.Msg{Key, Args}` (`msg("log.draftPick", "player", name, …)`) and
never builds sentences. Arg values are proper names and preformatted signed numbers (strings),
numbers (formatted per language by the UI), nested `Msg` for translatable references (`stat.kraft`,
`weather.regen`, `data.event.phoenix.name`) or lists (joined as "A, B und C"; args named `entries`
are joined with commas, `details`/`cards` with spaces). Errors are `invalid("err.…", …)` /
`gameservice.NewError(status, "err.…", …)`.

Views still carry the German data names as fallbacks, plus the ids the UI uses for lookups
(`web/src/i18n/data.ts`: `stationName`, `raceName`, `eventName`, `trainerName`, `boatName`, …).

## Checks

- `pnpm build` fails when an English UI or engine-message key is missing (the English catalogs are
  typed against the German ones).
- `TestMessageKeysInCatalog` (internal/engine) fails when Go code emits a key that is not in
  `messages.*.ts` (or `ui.*.ts`).
- `TestDataTranslations` (internal/data) fails when a data text has no English translation, a
  translation is stale, or numbers / `{placeholders}` differ from the German text.
- `TestDataGenUpToDate` fails when `data.gen.ts` was not regenerated.

## Adding a string

- UI: add the key to `ui.de.ts` and `ui.en.ts`, use `t("key", {param})` (or `tr` from
  `@/i18n/rich` for React nodes inside the text). Plurals: add `key_one` / `key_other` and pass
  `count`. Do not call `t()` at module top level; it would freeze the language.
- Engine: emit `msg("ns.key", …)` and add the key to both `messages.*.ts`.
- Data: change the German text in `internal/data/*.json`, the English one in `i18n/en.json`, then
  `just gen-i18n`.

## Glossary

| German                                                            | English                                               |
| ----------------------------------------------------------------- | ----------------------------------------------------- |
| Kraft / Ausdauer / Geschwindigkeit (Tempo) / Technik / Motivation | Strength / Endurance / Speed / Technique / Motivation |
| Eigenschaft                                                       | attribute                                             |
| Einer / Zweier / Vierer / Achter / Ergometer                      | Single / Double / Quad / Eight / Erg                  |
| Kinder / B-Junioren / A-Junioren                                  | Children / Juniors B / Juniors A                      |
| Krebs (fangen) / Kentern / Materialschaden                        | (catch a) crab / capsize / equipment damage           |
| Eventkarte / Ereignis                                             | event card / Happening                                |
| Trainingslager / Sonderveranstaltung / Spielvorbereitung          | Training camp / Special event / Setup                 |
| Gastmannschaft / städtisches Boot / Leihboot                      | guest crew / city boat / loan boat                    |
| Trainer / Laune / Siegesmotivation                                | coach / mood / win motivation                         |
| Ergo-Cup / Wanderfahrt                                            | Erg Cup / Rowing tour                                 |

Proper names stay (people, Maschsee, cities, JTFO, WR5); titles get English word order
("Regatta Bremen" → "Bremen Regatta").
